# Term Project - FRONTEND (DEV MODE)

## Setup
  ### 1. Clone Repository
  - git clone <URL's Repository>
  - cd TP-FRONTEND
  ### 2. Install Dependencies
  - pnpm install
  ### 3. Setting Environment Variables
  - create .env
  ### 4. Run web application 
  - pnpm run dev (development Mode)
  - docker compose up -d --build (docker)

## Usage
  - docker compose stop
