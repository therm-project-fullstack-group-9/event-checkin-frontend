# Term Project - FRONTEND (DEV MODE)

## Setup
  ### 1. Clone Repository
  - git clone <URL's Repository>
  - cd TP-FRONTEND
  ### 2. Install Dependencies
  - pnpm install
  ### 3. Setting Environment Variables
  - create .env 
  VITE_API_BASE_URL="http://localhost:5000/api"
  ### 4. Run web application (development Mode)
  - pnpm run dev
